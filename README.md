# Fitify 🥗  
AI-assisted nutrition tracking and food recognition application

Fitify is a mobile-first nutrition tracking application built as a final-year Computer Science project. The goal of the project is to simplify daily food logging and provide helpful nutrition insights using AI-assisted workflows, while keeping the experience clean, practical, and easy to use.

---

## 🚀 Features

- Food logging through manual entry and image scanning  
- AI-assisted food recognition from images  
- Gemini API fallback for interpreting food items when recognition confidence is low  
- Daily calorie and macro tracking  
- Personalized onboarding and user profile setup  
- Dashboard with progress overview and nutrition summaries  

---

## 🧠 How It Works

1. Users onboard by setting basic goals and dietary preferences  
2. Meals can be logged manually or by uploading food images  
3. Image-based food recognition attempts to identify food items  
4. When confidence is low, Gemini API is used as a fallback to generate nutrition-related insights  
5. Nutrition data is stored and visualized in the user dashboard  

The focus of the system is **usability and consistency**, not perfect nutritional accuracy.

---

## 🛠 Tech Stack

- **Frontend:** React, Tailwind CSS  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **AI Integration:** Gemini API (fallback analysis)  
- **Image Handling:** Cloudinary
